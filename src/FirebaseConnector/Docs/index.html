🏛️ Architecture Decision Records (ADR)

Formal records of high-impact engineering decisions, architectural trade-offs, and compliance constraints:

ADR-001: FCM HTTP v1 Migration

Adoption of modern OAuth2 Service Accounts and sunsetting deprecated Legacy FCM server keys.

Approved

ADR-002: Redis Sliding TTL Presence

45-second client heartbeat maintaining a 90-second sliding TTL in Redis with in-memory fallback.

Approved

ADR-003: Multi-Tenant Named FirebaseApp

Dynamic routing across separate Firebase projects based on appId and environment secrets.

Approved

ADR-004: Zero Secrets in Code

Strict exclusion of secrets from Git and appsettings; injection via .env and cloud secret managers.

Approved

ADR-005: Unified Multi-Type Payload

A single flexible API contract for Alert, Silent, Rich Media, Collapsible, and Topic broadcasts.

Approved

ADR-006: Multi-App Token Isolation & Broadcast

Cryptographic token isolation per app ID and Pub/Sub topic broadcasting to App A without affecting App B.

Approved
