🐳 Container & Cloud Deployment Guide

Production operations manual for running the .NET 8 Push Gateway with Podman Compose, Docker, Kubernetes, and secure environment variable secrets.

Zero Hardcoded Credentials

The gateway binary contains zero secrets. All Google Firebase OAuth2 Service Account keys and Redis connection strings are injected at runtime via environment variables or container secrets.

1. The Container Architecture

2. Running with Podman / Docker Compose

TerminalBash / PowerShell
# 1. Build and start both API and Redis in the background:
podman-compose up -d

# 2. Inspect streaming logs:
podman logs -f fcmpoc-api

# 3. Check health and running status:
podman ps

# 4. Stop containers gracefully:
podman-compose down

3. The Compose Configuration (podman-compose.yml)

podman-compose.ymlYAML
version: '3.8'

services:
  fcmpoc-redis:
    image: redis:7-alpine
    container_name: fcmpoc-redis
    restart: unless-stopped
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data

  fcmpoc-api:
    image: localhost/fcmpoc-api:latest
    build:
      context: .
      dockerfile: Dockerfile
    container_name: fcmpoc-api
    restart: unless-stopped
    ports:
      - "5000:5000"
    environment:
      - ASPNETCORE_ENVIRONMENT=Production
      - ASPNETCORE_URLS=http://+:5000
      - REDIS_CONNECTION=fcmpoc-redis:6379
    env_file:
      - .env
    depends_on:
      - fcmpoc-redis

volumes:
  redis-data:

4. Environment Variable Configuration (.env)

Place your .env file in the project root alongside podman-compose.yml:

.envBash
# Redis Connection
REDIS_CONNECTION=fcmpoc-redis:6379

# Default / Primary Firebase App
FIREBASE_APP_FCMPOC_JSON='{"type":"service_account","project_id":"fcmpoc-connector",...}'

# Tenant App 1: Existing Customer App
FIREBASE_APP_CUSTOMERAPP_JSON='{"type":"service_account","project_id":"my-customer-firebase",...}'

# Tenant App 2: Existing Driver App
FIREBASE_APP_DRIVERAPP_JSON='{"type":"service_account","project_id":"my-driver-firebase",...}'

# Tenant App 3: Existing Merchant App (Base64 encoded string supported!)
FIREBASE_APP_MERCHANTAPP_JSON=eyJ0eXBlIjoic2VydmljZV9hY2NvdW50IiwicHJvamVjdF9pZCI6Im1lcmNoYW50In0=

5. Production Kubernetes Manifest (EKS / GKE / AKS)

Deploying into a high-availability Kubernetes cluster:

k8s-deployment.yamlYAML
apiVersion: apps/v1
kind: Deployment
metadata:
  name: fcm-connector-deployment
  labels:
    app: fcm-connector
spec:
  replicas: 3
  selector:
    matchLabels:
      app: fcm-connector
  template:
    metadata:
      labels:
        app: fcm-connector
    spec:
      containers:
      - name: fcm-connector
        image: your-registry.azurecr.io/fcm-connector:latest
        ports:
        - containerPort: 5000
        env:
        - name: ASPNETCORE_URLS
          value: "http://+:5000"
        - name: REDIS_CONNECTION
          value: "redis-cluster.cache.amazonaws.com:6379"
        envFrom:
        - secretRef:
            name: fcm-service-account-secrets
        resources:
          limits:
            cpu: "1000m"
            memory: "512Mi"
          requests:
            cpu: "250m"
            memory: "256Mi"
        readinessProbe:
          httpGet:
            path: /swagger
            port: 5000
          initialDelaySeconds: 5
          periodSeconds: 10

6. Production Ops FAQ & Troubleshooting

Q: Why does the API return "Status": "UserInactive"?

A: The payload specified "onlyIfActive": true, but the device's 90-second sliding presence expired or was never initialized. Send a heartbeat via POST /api/presence/heartbeat or pass "onlyIfActive": false.

Q: Why did Google FCM return "InvalidArgument" error?

A: The device token passed is either a synthetic mock token (e.g. fcm_mock_...) or malformed. Real tokens must originate from the client device calling Firebase SDK getToken().

Q: How do we rotate Apple APNs keys or Firebase Service Account keys?

A: For Apple APNs, replace the .p8 key in Firebase Console without downtime. For Google Service Accounts, generate a new key in Google Cloud IAM, update your .env or Kubernetes secret, and trigger a rolling deployment.
