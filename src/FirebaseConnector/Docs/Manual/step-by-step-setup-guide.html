🛠️ Step-by-Step Setup & Verification Guide

Complete button-by-button walkthrough: creating your Google Firebase project, generating OAuth2 Service Account credentials, deploying via Podman/Docker, and verifying real push delivery.

Who is this manual for?

This guide is written for any engineer wanting to set up and verify the Firebase Push Connector from scratch in under 15 minutes without guessing what buttons to click in Google Cloud.

Phase 1: Firebase Console Setup (Click-by-Click)

Follow these exact steps in your web browser:

Step 1.1: Create the Firebase Project

  1. Open https://console.firebase.google.com/ and log in with your Google account.
  2. Click the card labeled + Add project (or Create a project).
  3. Step 1 of 3: Name your project (e.g., fcmpoc-connector), accept the terms, and click Continue.
  4. Step 2 of 3: Disable Google Analytics toggle (simplifies setup for testing) and click Create project.
  5. Wait 20 seconds for provisioning. When it displays "Your new project is ready", click Continue.

Step 1.2: Generate the Backend Service Account Key (.json)

This is the master OAuth2 credential that authorizes your .NET backend to send notifications via the FCM HTTP v1 API:

  1. In the top-left sidebar of the Firebase Console, locate Project Overview.
  2. Click the Gear Icon (⚙️) immediately to the right and select Project settings.
  3. Switch to the Service accounts tab at the top.
  4. Under Firebase Admin SDK, click the blue button: Generate new private key.
  5. A confirmation modal will appear warning you to keep the key confidential. Click Generate key.
  6. Your browser downloads a file named like fcmpoc-connector-firebase-adminsdk-xxxxx.json.
  7. Place this file in your project secrets folder: secrets/firebase_key.json or copy its contents into your .env file.
Corporate Organization Policy Edge Case

If your enterprise Google Cloud organization enforces iam.disableServiceAccountKeyCreation, key creation may be blocked. To resolve this, ask your GCP admin for a key-creation exemption for this project, or use a personal Google account for local POC validation.

Phase 2: Setting Up the Fast Client Receiver (Web Simulator)

To test real notifications immediately without compiling a mobile Android APK or iOS app:

  1. In Firebase Console > Project settings > General tab, scroll down to Your apps.
  2. Click the Web icon (</>).
  3. Enter an app nickname (e.g. TestWebClient) and click Register app.
  4. Copy the generated firebaseConfig object (contains apiKey, projectId, messagingSenderId, appId).
  5. Open mobile-simulator/index.html in your project, paste these values into the configuration section, and save.

Phase 3: Running the Backend (Podman or .NET CLI)

Option A: Using Podman Compose / Docker Compose (Recommended)

TerminalBash / PowerShell
# 1. Create your .env configuration
cp .env.example .env

# 2. Add your service account JSON into .env
# FIREBASE_APP_FCMPOC_JSON='{"type":"service_account", ...}'

# 3. Spin up both Redis 7 and the .NET 8 API:
podman-compose up -d
# or: docker compose up -d

# 4. View live logs:
podman logs -f fcmpoc-api

Option B: Using .NET 8 CLI Locally

TerminalBash / PowerShell
# 1. Start Redis in background:
podman run -d --name fcmpoc-redis -p 6379:6379 redis:7-alpine

# 2. Run the .NET API:
dotnet run --project "src/FirebaseConnector/FirebaseConnector.csproj"

Phase 4: Step-by-Step Delivery Verification

  1. Open the Web Simulator: Navigate to http://localhost:5000/simulator in Chrome or Edge.
  2. Grant Notification Permission: Click the browser prompt to Allow notifications.
  3. Obtain Real Device Token: Click "Register / Login". The simulator fetches a genuine Google-issued cryptographic FCM Device Token and automatically posts it to POST /api/devices/register.
  4. Start Heartbeat: The simulator begins transmitting a 45-second heartbeat, establishing a 90-second active presence window in Redis.
  5. Trigger Push Notification: Open http://localhost:5000/swagger or run this curl command:
    Curl CommandBash / PowerShell
    curl -X POST http://localhost:5000/api/notifications/send \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "test_user_simulator",
    "title": "Delivery Arrived! 🍕",
    "body": "Your order #1082 has been delivered.",
    "onlyIfActive": true,
    "priority": "High"
  }'
  6. Verify: A system notification banner pops up on your Windows/Mac desktop screen within 1–2 seconds!
