ADR-004 Approved

Zero Secrets Committed: Environment Variable Secret Pattern

Eliminating committed private keys and establishing a robust 12-factor runtime secret injection pattern with Base64 support.

1. Context & Problem Statement

Google Cloud Service Account JSON credentials contain sensitive private RSA keys (-----BEGIN RSA PRIVATE KEY-----). Committing these files to Git repositories presents severe security risks:

  • Automated bots continuously scrape public and private repositories for leaked credentials.
  • Accidental commits compromise enterprise infrastructure, triggering emergency key rotation and audit inquiries.
  • Hardcoding file paths like /app/keys/service-account.json breaks portability between local workstations, CI/CD runners, and cloud container runtimes.

2. Decision Drivers

  • Strict compliance with the Twelve-Factor App methodology (Config stored in environment).
  • Zero sensitive private key files tracked in source control.
  • Compatibility with diverse cloud secret engines (Kubernetes Secrets, AWS Secrets Manager, Azure Key Vault, HashiCorp Vault).
  • Support for CI/CD environments that do not permit multiline strings in environment variables.

3. Decision Outcome

Approved Decision: Enforce zero committed secrets across the codebase and support dual raw JSON / Base64-encoded environment variables:

  1. All *.json credential files and .env files are strictly gitignored in .gitignore.
  2. The application accepts credentials exclusively via environment variables matching: FIREBASE_APP_<NAME>_JSON.
  3. FirebaseAppManager inspects the variable value:
    • If the string begins with {, it is parsed directly as JSON.
    • If the string does not begin with {, the manager automatically decodes it from Base64 into UTF-8 JSON.

4. Implementation Snippet

Services/FirebaseAppManager.csC#
private static string NormalizeSecret(string rawSecret)
{
    var trimmed = rawSecret.Trim();
    if (trimmed.StartsWith("{"))
    {
        return trimmed;
    }

    // Decode Base64 string for CI/CD environments
    var bytes = Convert.FromBase64String(trimmed);
    return Encoding.UTF8.GetString(bytes);
}

5. Consequences

Positive Impact
  • Audit & Compliance Ready: Passes automated SOC2, ISO 27001, and GitGuardian compliance audits.
  • Seamless DevOps: Secrets can be securely mounted in Kubernetes via secretKeyRef or injected directly in Docker Compose.
  • Safe Local Development: Developers use uncommitted .env files with zero risk of pushing credentials upstream.
