🏛️ Architecture Decision Records (ADR)

Formal documentation capturing significant architectural decisions, business trade-offs, and design rationale across the system lifecycle.

What is an ADR?

An Architecture Decision Record (ADR) captures an important architectural decision made along with its context and consequences. Each record follows the Michael Nygard template (Context, Decision, Consequences, Status).

ADR-001

FCM HTTP v1 Protocol

Retires the deprecated FCM Legacy Server Key API in favor of Google OAuth2 Service Accounts and short-lived tokens.

Redis Sliding TTL Presence

Uses a 45s client ping and 90s sliding expiration in Redis to prevent sending wasteful pushes to idle devices.
