🍎 Apple iOS & APNs Integration Guide

Everything you need to know about delivering push notifications to iPhones, iPads, and iOS Safari using Firebase Cloud Messaging.

The Fundamental Rule: Zero Backend Changes Needed

Our .NET Firebase Connector handles both Android and iOS devices transparently. You never write APNs code in the backend. Google FCM acts as the official bridge to Apple APNs servers.

1. The Master APNs Key (.p8): What is it & Is it different per device?

NO, it is NOT different for each device!

The APNs Key is ONE single master credential for your entire Apple Developer Account:

  • Think of it as your company's Master Passkey. It tells Apple that Google Firebase has your official permission to deliver notifications to any of your iOS apps.
  • You generate it ONCE in the Apple Developer Portal and upload it ONCE to Firebase Console.
  • You never install or put the .p8 key on user devices or inside mobile app code.
Concept What is it? How many exist? Where does it go?
Apple APNs Key (.p8) Company master authorization signature. Exactly 1 for your whole company / team. Uploaded once into Firebase Console.
Device Token (FCM Token) The unique digital address of one specific phone. Unique for every device (Alex's phone has one, Bob's has another). Sent by the mobile app to our backend (POST /api/devices/register).

2. Step-by-Step Apple Developer Portal Walkthrough

Step 2.1: Generate an APNs Authentication Key (.p8)

  1. Log in to developer.apple.com/account.
  2. Go to Certificates, Identifiers & Profiles > Keys.
  3. Click the `+` button to create a new key.
  4. Name the key (e.g., FCM APNs Key).
  5. Check the box for Apple Push Notifications service (APNs).
  6. Click Continue > Register.
  7. Download the key file (named AuthKey_XXXXXXXXXX.p8). Save it securely; Apple allows only 1 download!
  8. Note down your:
    • Key ID: 10-character string shown next to the key.
    • Team ID: 10-character string in the top-right corner of your Apple Developer account.

Step 2.2: Upload the `.p8` Key to Firebase Console

  1. Open Firebase Console and select your project.
  2. Click the Gear icon (⚙️) > Project settings.
  3. Switch to the Cloud Messaging tab.
  4. Scroll down to Apple app configuration.
  5. Under APNs Authentication Key, click Upload.
  6. Select your .p8 file, paste your Key ID and Team ID, and click Upload.

3. Xcode Capabilities (Required for iOS App)

In your iOS project in Xcode:

  1. Select your target > Signing & Capabilities.
  2. Click `+ Capability` and add Push Notifications.
  3. Click `+ Capability` again and add Background Modes:
    • Check Remote notifications (Required for Silent Push background execution!).
    • Check Background fetch.

4. How to Test iOS Push Without a Mac or App Store (Workaround)

Since iOS 16.4, Apple Safari supports native Web Push Notifications:

  1. Expose port 5000 over HTTPS using ngrok http 5000 or Cloudflare Tunnel.
  2. Open Safari on an iPhone and navigate to https://xxxx.ngrok-free.app/simulator/index.html.
  3. Tap Share > Add to Home Screen (required by iOS).
  4. Launch from Home Screen, tap Login, and allow the native iOS push prompt.
  5. Send a notification from our API — your iPhone lock screen will light up with an authentic Apple notification!
